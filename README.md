# LIF Explorer — LIF Studio v2.1

Offline Leica LIF microscopy viewer by Lennikov Lab. The v2.1 browser application reads compatible Leica `.lif` projects locally without uploading experimental images.

**Recovered version:** v2.1, October 14, 2026. Supports Z/T/C microscopy series, maximum-intensity projections, orthogonal and 3D views, channel adjustment, calibrated measurements, colocalization and OME-TIFF export.

**Build:** Open `LIF_Studio.html` in a modern desktop browser. Code is maintained in `src/`; a reproducible build script and validation guidance are also provided.

**Scientific limits:** Only conventional uncompressed 8/16-bit LAS AF/LAS X LIF layouts are supported; independent comparison with LAS X is needed before quantitative use. Not affiliated with Leica Microsystems. No open-source license granted unless added explicitly.
