LIF STUDIO / QUICK GUIDE
A workspace for your microscopy
Open a Leica .lif project, then choose a series from the explorer. Z selects a section; T selects a timepoint. The maximum projection combines all Z planes at the selected timepoint.
Channels. Toggle channels, choose colors and adjust the display minimum, maximum and gamma. Auto range uses each channel’s observed minimum and maximum. These controls affect display exports, not raw TIFF data.
Histograms and layouts. Drag the black/white limits on a channel histogram, or use its sliders and numeric fields. Counts are shown on a log scale; the source (plane, projection or sampled 3D preview) is labeled. Four channels + merged displays four assignable channels beside the combined image. Explorer thumbnails preview the middle Z plane at T1, with independent preview scaling.
Colocalization. Choose two channels and analyze a selected Z plane, the original full Z stack at the current timepoint, or a maximum projection. Drag a rectangle on the overlay for an ROI, or enter its pixel coordinates. For a stack, the same XY rectangle applies to every Z plane. The stack image previews one plane; scores use every original voxel.
Scores. Pearson r ranges from −1 to +1. Manders M1 is ΣA where B exceeds its raw threshold, divided by all A intensity in the region; M2 reverses the channels. Threshold comparisons are strictly greater than. The joint-positive percentage reports the fraction of ROI pixels/voxels above both thresholds. Constant channels or zero denominators can give undefined scores. Colors and display contrast do not change the analysis.
Thresholds and interpretation. Enter raw thresholds or use Otsu suggestions, which use a native-intensity histogram of the analyzed region. Otsu is separate from Costes. Projection overlap can combine signals from different depths; use a plane or raw stack for spatial analysis. Background and spectral bleed-through can influence correlation. CSV/JSON exports retain settings and formulas; no significance test is calculated.
Scale. X, Y and Z spacing are read from LIF metadata when available. You can override them manually. With no physical calibration, use a pixel scale bar. In 3D, scale is a reference in the lateral XY units; depth exaggeration changes the Z appearance.
Memory. Automatic mode uses lower memory on Mac. Files open as one Z plane; projections and 3D prepare only when selected. The memory selector changes preview budgets and remembers your choice. Original pixels and quantitative analysis retain their source resolution. Use Download troubleshooting details if a problem persists.
3D. Drag to rotate; scroll to zoom. Choose an axis, direction, speed or angular sweep for autorotation. Red–cyan glasses and video export are at the bottom of the control panel.
Exports. PNG, JPG and display TIFF capture the current view in 8-bit RGB. Raw OME-TIFF preserves 8/16-bit unsigned intensities, channels, Z/T dimensions and available calibration. Raw exports exclude display overlays. Classic TIFF and browser memory limits apply.
File support. Conventional uncompressed 8/16-bit LAS AF/LAS X LIF images. Specialized FLIM, packed pixels and other unsupported layouts are reported explicitly. Validate a representative image against LAS X before quantitative use.
Local processing. Image files are read on your computer. No image upload, Leica installer or microscope connection is required. Reloading clears the session. The offline app contains the same features as this version.
Format references: OME Bio-Formats · liffile. Independent software; not a Leica product.
